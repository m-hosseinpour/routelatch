# مستندات RouteLatch

تاریخ ایجاد: ۲۰۲۶-۱۱-۱۷

این پوشه نتیجهٔ طوفان فکری و بررسی دو پیاده‌سازی قبلی و منابع عمومی است.
**پروژه هنوز اپ اجرایی، سرویس نصب‌شده یا نتیجهٔ آزمون اجرایی ندارد.**

| سند | مرجع اصلی برای |
| --- | --- |
| [نیازمندی‌ها](requirements.md) | تصمیم‌های کاربر، رفتار محصول و معیارهای پذیرش |
| [معماری](architecture.md) | طرح پیشنهادی، مرز اجزا، امنیت و خطرهای فنی |
| [شواهد](research.md) | قابلیت‌های بررسی‌شده، منابع، نسخه‌ها و محدودیت تحقیق |
| [پلن](implementation-plan.md) | ترتیب کار، وابستگی‌ها، دروازه‌های پذیرش و وضعیت کار |

برای ادامهٔ کار در جلسهٔ دیگر، [قواعد مخزن](../AGENTS.md) و سپس
[کارهای باز و وضعیت ادامه](implementation-plan.md#open-work) را بخوانید.
فهرست تسک‌ها و وضعیت در `AGENTS.md` تکرار نمی‌شوند.

تصمیم‌های محصول فقط در `requirements.md` مرجع‌اند؛ سند معماری و پلن به شناسهٔ
آن‌ها ارجاع می‌دهند. وضعیت ادامهٔ کار فقط در پلن نگهداری می‌شود.

## شیوهٔ خواندن

- **تصمیم کاربر:** در گفت‌وگو انتخاب شده؛ تغییر آن نیاز به تصمیم جدید دارد.
- **مستند/بررسی‌شده از سورس:** متن منبع یا کد خوانده شده؛ اجرای واقعی را اثبات نمی‌کند.
- **طرح پیشنهادی:** راه رسیدن به تصمیم محصول؛ جزئیاتش با شواهد جدید قابل اصلاح است.
- **دروازهٔ فنی:** موضوعی که قبل از اجرای بخش وابسته باید با آزمون بسته شود.

ابتدا نیازمندی‌ها، سپس معماری و دروازهٔ `T1` در پلن را بخوانید. پیاده‌سازی اصلی
نباید بر مبنای تصور «Xray Dial موفق شد، پس مقصد واقعاً وصل شده» شروع شود.

## استقلال و اطلاعات خصوصی

دو پروژهٔ قبلی فقط مرجع تحقیق‌اند، نه وابستگی محصول. واردکردن دادهٔ آن‌ها اختیاری
و صریح است و فایل‌های اصلی را تغییر نمی‌دهد. این مستندات شامل share link واقعی،
توکن، کوکی، فهرست مقصدهای شخصی یا اطلاعات ورود نیستند.

برای شواهد داخلی از نام پروژه، مسیر نسبی و revision استفاده شده؛ مسیرهای شخصی
ماشین و جزئیات حساب‌ها وارد مستندات عمومی نشده‌اند.
